# 🌱 AGRIGUIDE – AI CROP RECOMMENDATION SYSTEM

AGRIGUIDE is a full-stack college project for crop recommendation using Flask, SQLite and a scikit-learn classification model.

## Features
- Farmer registration/login/logout
- Password hashing
- Responsive farmer dashboard
- Real user-entered crop prediction
- 22 crop classes in the bundled model
- ML inputs: N, P, K, temperature, humidity, rainfall, pH
- Transparent soil/water/season compatibility layer
- Top 3 recommendations
- Crop health status
- Prediction history with delete/clear
- Mobile-friendly layout
- 404/500 handling
- GitHub/deployment-ready
- Gunicorn production start command

## Important ML note
The ML model uses exactly these seven numeric features:
`N, P, K, temperature, humidity, rainfall, ph`

Soil type, water availability and season are **not** claimed as ML features. They are applied after the ML result by a separate compatibility/rule layer.

The bundled `data/crop_data.csv` is a self-contained teaching dataset generated by `model/train_model.py`, so the project can run without downloading a dataset. For research or a production agricultural system, replace it with a verified standard crop recommendation dataset and retrain the model.

## Local setup

### 1. Create/activate a virtual environment
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Train/retrain the model
```bash
python model/train_model.py
```

### 4. Start Flask
```bash
python app.py
```

Open:
`http://127.0.0.1:5000`

## Deployment
Production start command:
```bash
gunicorn app:app
```

Set an environment variable named `SECRET_KEY` to a strong random value on the hosting platform.

### GitHub
1. Create a GitHub repository.
2. Upload the project files/folders.
3. Commit and push.
4. Connect the repository to your Python hosting provider.
5. Build/install command:
```bash
pip install -r requirements.txt
```
6. Start command:
```bash
gunicorn app:app
```

If the host provides a dynamic `PORT`, the Flask development server also respects it.

## Testing checklist
- Register a new farmer
- Confirm duplicate phone is blocked
- Login with the registered account
- Confirm the real farmer name appears
- Open Crop Prediction
- Enter different values
- Confirm prediction is not hard-coded to one crop
- Confirm result shows the actual entered values
- Confirm health status appears
- Confirm history saves
- Confirm history is private to the logged-in farmer
- Delete one record
- Clear history
- Logout and log in again
- Confirm history persists
- Test around 360px, 390px, 412px, 768px and desktop widths
