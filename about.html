ABOUT THE PROJECT

AGRIGUIDE

A beginner-friendly full-stack college project combining Flask, SQLite and scikit-learn.

How the recommendation works

The ML classifier receives exactly seven numeric features: N, P, K, temperature, humidity, rainfall and pH. Soil type, water availability and season are not passed into the ML model; they are evaluated by a separate compatibility layer.

Security & data

Passwords are stored as hashes. SQLite queries use parameters, and prediction history is filtered by the logged-in farmer's user ID.

Project limitation

The bundled dataset is self-contained teaching data so the project can run without downloading a dataset. For academic research, replace it with a verified standard crop dataset and retrain the model.

Future improvements

Weather APIs, regional soil datasets, Kannada localization, disease-image diagnosis and field-specific agronomy validation can be added later.
